# ЛЕСНА ДИПЛОМНА

Уеб приложение за подаване и управление на заявки за дипломни проекти (УКТЦ).

## Функционалности

- **Стъпков въпросник (Wizard)**:
  - Въвеждане на име, 5-цифрен ученически номер (автоматично генериране на служебен имейл `@uktc-bg.com` и цифрова клавиатура за мобилни устройства), контакт, дипломен ръководител, тема, обхват, сложност и бюджет.
  - Генериране на уникален тикет номер (`UKTC-2026-XXXX`).
  - Автоматично изпращане на имейл потвърждение чрез **Resend**.
- **Административен панел (`/admin`)**:
  - Защитен достъп с ПИН ключ (`ADMIN_SECRET_KEY`).
  - Интерактивна **3D графика** за статистика по статус (Чакащи/Одобрени, В разработка, Завършени) с въртене и филтриране с клик.
  - Търсене, филтриране, вътрешни бележки и 1-клик одобряване/отхвърляне или изпращане на персонализиран имейл.

## Технологии

- **Next.js 16** (App Router, Turbopack) + **React 19** + **TypeScript**
- **Tailwind CSS v4** + **Framer Motion**
- **Prisma 7** + **LibSQL / SQLite** (`@libsql/client`, Turso)
- **Resend** (имейл известия) + **Zod** (валидация и защита)

## Настройка (Environment Variables)

Създайте `.env` файл в основната директория:

```env
DATABASE_URL="file:./dev.db"
TURSO_AUTH_TOKEN=""
ADMIN_SECRET_KEY="uktc2026admin"
RESEND_API_KEY="re_..."
RESEND_FROM_EMAIL="Дипломни УКТЦ <noreply@bgtulk.dev>"
RESEND_TEST_FALLBACK_EMAIL="your-email@gmail.com"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

## Стартиране локално

```bash
npm install
npm run dev
```

Приложението ще е достъпно на `http://localhost:3000`, а админ панелът на `http://localhost:3000/admin`.

## Деплой във Vercel

1. Импортирайте GitHub хранилището във **Vercel**.
2. Задайте променливите от `.env` в **Environment Variables** (за облачна база използвайте `libsql://...` от **Turso** в `DATABASE_URL` и токена в `TURSO_AUTH_TOKEN`).
3. Таблицата `Ticket` се инициализира автоматично при първа заявка.
